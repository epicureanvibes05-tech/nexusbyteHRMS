# Phase 0 threat model

Date: 2026-09-18. Source: [Master](../requirements/FINAL-MASTER-REQUIREMENTS.md) §§3, 8, 10, 14, 22–26, 28–32. This is a repository-based design assessment, not a penetration test or a claim that controls passed. All planned controls require verification. See [baseline](../architecture/CURRENT-BASELINE.md) and [conflict register](../requirements/RECONCILIATION-REPORT.md).

## Assets, actors and trust boundaries

Protect credentials/session material, HR identity/contact/medical/grievance data, salary and financial history, private documents, permissions, audit evidence, device events, backups and encryption keys. Threat actors include unauthenticated outsiders, compromised employees, over-privileged insiders, compromised devices/providers and operators making accidental destructive changes.

Current boundaries: untrusted browser → Next.js route/server code → session/auth helpers → Prisma/database; administrative seed/bootstrap scripts → database; application errors → operator logs. Cookies cross the browser/server boundary. Future boundaries include company/tenant partitions, private object storage/downloads, job workers, device connectors, exports/email, secret stores and off-host backups. These future services are not present merely because this threat model names them.

## Release gates and residual risk

The current source does not establish production readiness. Resolve foundational auth/scope/session/history conflicts and verify relevant §28 scenarios before exposing dependent features. Approve OD-15–18 before sensitive production storage/recovery, OD-01–14 before dependent legal/payroll behavior, and provider/device decisions before those integrations. Provider-independent contracts, mock fixtures and neutral configuration remain possible in a later authorized phase.

No risk acceptance, legal approval, live exploit, data breach, penetration-test result or successful restore is asserted. Operational TLS, database grants, backup encryption and hosting defenses are unknown. Reassess this model after each implemented boundary change and record control evidence, accountable owner and any explicitly accepted residual risk.
